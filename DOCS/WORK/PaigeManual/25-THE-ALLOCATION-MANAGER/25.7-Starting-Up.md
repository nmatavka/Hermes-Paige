## 25.7 Starting Up

The Allocation Manager must have already been started before `Y` was called. You need to make any function calls to initialise this portion of the software. To start HERMES Paige with the Allocation Manager and for details on `pgMemStartup`, see section 2.4, [Software Startup](#2.4-software-startup).

**CAUTION:** You must not, however, use any functions listed below unless you have called `pgMemStartup`.

**NOTE:** You can theoretically use the Allocation Manager, by itself, without ever initialising HERMES Paige.
