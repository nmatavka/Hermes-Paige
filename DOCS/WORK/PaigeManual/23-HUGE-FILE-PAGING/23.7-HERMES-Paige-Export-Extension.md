## 23.7 HERMES Paige Export Extension

If you are saving file(s) with the HERMES Paige export extension, you can cause the same effect as `pgCacheSaveDoc()` by setting the `EXPORT_CACHE_FLAG` bit in the `export_flags` parameter—see chapter 18, [HERMES Paige Export Extension](#18-hermes-paige-export-extension).
